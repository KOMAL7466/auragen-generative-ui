## Project Summary

AuraGen is an AI-powered real estate platform that:
1. Detects when users struggle (Cognitive Load Engine)
2. Adapts the UI accordingly (Adaptive UI)
3. Provides contextual AI guidance (RAG + Gemini)

**Core Flow:**
User → Event → Cognitive Load → Adaptive UI → Guidance
