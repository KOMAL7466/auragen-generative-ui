# AuraGen Real Estate Knowledge Base

## 1. Real Estate Basics

Real estate refers to land and properties such as residential houses, apartments, commercial buildings, and other structures attached to land.

Common property types include:
- Apartment
- Independent House
- Villa
- Plot
- Commercial Property

## 2. Property Information

Important property details include:
- Location
- Property type
- Price
- Size
- Number of bedrooms
- Number of bathrooms
- Amenities
- Nearby facilities
- Property purpose

Property purpose may include:
- Personal use
- Rental
- Investment

## 3. Property Evaluation

When evaluating a property, users may consider:
- Location
- Price
- Property size
- Property type
- Amenities
- Nearby schools and hospitals
- Transportation access
- Rental potential
- Investment purpose

## 4. Investment Concepts

Real-estate investment means purchasing property with the intention of generating value or income.

Users may evaluate:
- Property price
- Expected rental income
- Location
- Future development
- Demand
- Rental suitability
- Potential return

AuraGen should explain investment-related concepts in simple language and should not present uncertain information as guaranteed financial returns.

## 5. Rental Suitability

A property may be considered suitable for rental based on factors such as:
- Location
- Rental demand
- Property type
- Size
- Nearby facilities
- Transportation
- Expected rental income

## 6. Property Comparison

Users may compare properties using:
- Price
- Location
- Size
- Bedrooms
- Property type
- Amenities
- Rental suitability
- Investment purpose

AuraGen should present comparisons clearly and explain important differences.

## 7. Buying Process

A general property buying process may include:
1. Define requirements
2. Search for properties
3. Compare properties
4. Visit or inspect the property
5. Evaluate price and suitability
6. Review relevant documents
7. Complete the required transaction process

Specific legal, financial, and documentation requirements may vary depending on the location.

## 8. Common Real Estate Terms

### Property Price
The listed or quoted price of a property.

### Property Size
The area or size of a property, commonly expressed using units such as square feet.

### Amenities
Facilities or features provided with or near a property, such as parking, security, gym, swimming pool, or recreational facilities.

### Rental Income
Money received from renting a property to a tenant.

### Investment
Purchasing an asset with the expectation that it may provide value or income in the future.

### Location
The geographical area where a property is situated.

## 12. Cognitive Load and Adaptive Experience

AuraGen monitors interaction signals such as:
- Time spent
- Repeated clicks
- Validation errors
- Back-and-forth navigation
- Inactivity
- Repeated attempts
- Help requests

The system can classify cognitive load as:
- LOW
- MEDIUM
- HIGH

The adaptive experience may:
- Keep the normal interface for LOW load
- Highlight important information for MEDIUM load
- Provide contextual explanations
- Simplify complex sections for HIGH load
- Highlight the important next action
- Reduce unnecessary information

Important functionality should not be removed simply because cognitive load is high.
